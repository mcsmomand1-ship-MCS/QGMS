# QGMS Final UI Design Reference

This file contains the final UI design reference for the AOU Quiz and Grade Management System.

## General UI Rules

All groups must follow these design rules:

1. Use the same QGMS color theme.
2. Use the same button style.
3. Use the same font style.
4. Use clean spacing.
5. Use clear labels.
6. Use red star (*) for required fields.
7. Use clear error and success messages.
8. Do not make screens crowded.
9. Teacher screens should use sidebar/menu layout.
10. Student quiz screens should be simple and focused.
11. Student quiz screens should not show teacher sidebar menu.

## Final Screens

The final system should include:

1. Login Form
2. Teacher Dashboard
3. Add Question Form
4. View Questions Form
5. Student Start Quiz Screen
6. Student Quiz Screen
7. Teacher Grading Screen
8. Result Report Screen
9. Result Details Screen
