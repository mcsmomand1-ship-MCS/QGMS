# QGMS - Quiz and Grade Management System

QGMS is a Java Desktop Application project developed using Java Swing, MySQL, and JDBC.

This project is developed by students as a group project.

## Project Title

AOU Quiz and Grade Management System

## Main Users

1. Teacher
2. Student

## Main Features

### Teacher Features

- Login as Teacher
- View Teacher Dashboard
- Add Questions
- View Questions
- Grade Short Answer / Descriptive Answers
- View Student Results
- View Result Details

### Student Features

- Login as Student
- Select Quiz
- Answer MCQ Questions
- Answer Short Answer / Descriptive Questions
- Submit Quiz

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- GitHub
- Figma
- MySQL Workbench
